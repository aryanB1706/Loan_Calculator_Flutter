- Primary `#0075FF`, dark blue `#0F4B92`, mint `#14E99F`, success `#00C48B`
- Text `#3A3A3A`, secondary text `#757575`, border `#DADADA`
- Font: Montserrat 400/500/600
- Radii: 6 (buttons), 8 (inputs), 12 (cards), 70 (pills)
